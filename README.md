# 🧠 MNIST Handwritten Digit Classification

## 📌 Project Overview
This project builds a machine learning model to classify handwritten digits (0–9) using the MNIST dataset.

The goal is to train a supervised classification model capable of accurately predicting handwritten digit images.

---

## 📊 Dataset
MNIST dataset containing 28×28 grayscale handwritten digit images.
Each image is represented as 784 pixel values.

---

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

---

## 🤖 Model Used
Random Forest Classifier

---

## 📈 Evaluation Metrics
- Accuracy Score
- Classification Report
- Confusion Matrix

---

## 🎯 Result
The model achieves high classification accuracy on unseen test data.
